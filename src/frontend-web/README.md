## 🏁 **Analogía del Auto de Carreras**

Este componente representa el **Tablero de Mandos (Dashboard de Analíticas)** de nuestro vehículo EquineLead:
- **Rol**: Panel centralizado para visualizar el rendimiento de los leads, embudos de venta y análisis de sentimiento.
- **Mantenimiento**: Verificado automáticamente por `Jenkinsfile.frontend`.
